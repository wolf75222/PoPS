# Route identity preparation before exact consensus

InterfaceFluxScheduler::install previously serialized its owning route identity string outside a voted exception boundary. A rank-local allocation failure could escape while peers entered the following byte consensus. The private prepare_collective_plan_identity_ helper now captures any serializer exception, finishes the existing execution-communicator preflight vote, and returns the prepared string only after all ranks admitted preparation. The throwing rank retains its original exception; peers reject before byte consensus. No route is installed or evaluator factory called by this phase, and retry prepares fresh storage.

The serial path preserves the original exception. The default communicator string is now empty until its existing assignment inside the structural preflight, avoiding a possible allocation before that try block. Registry identities, route materialization (including the physical certificate), and evaluator preparation already have voted boundaries. The empty PreparedInterface member constructors use default empty containers/views; registry reserve precedes final publication. Caller-side route/factory argument construction remains outside this function's admission boundary.

The serializer, byte keys/order/cardinality/communicator and numerical operations are unchanged. There is no public layout, wire or ABI change; ABI11 remains applicable. The modified SDK header requires a fresh HeaderSignature and rebuild. No contract-string version bump is needed because the serialized identity is unchanged.

The Source/Host probe tests/review/interface_route_identity_preflight.cpp compiles actual headers with -fno-access-control solely to exercise the private preparation stage. It links readonly MPICH/PMPI and Kokkos without a PoPS Native DSO. Global operator-new injection fails the first real serialization allocation on each MPI rank in turn; successful, failed and retried stages compare the exact original serializer bytes, including embedded-NUL identities and non-square geometries in Dim1/2/3. MPI_Allreduce interception records and forwards real PMPI calls; it does not invent peer outputs. A two-rank launch is explicitly required by --mpi2. The old raw serializer remains an unvoted rank-local control. This stage probe does not qualify the complete scheduler, Native System runtime, CUDA or scientific evolution.
