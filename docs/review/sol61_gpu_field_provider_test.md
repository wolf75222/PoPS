# Genuine native-memory FieldSolver test preparation

The test component declares the actual backend target and retains FieldTopologyV2/FieldSolverV2 tables. It uses DefaultExecutionSpace and its actual memory_space; it refuses a different solution memory/scalar/component contract. Immutable Host topology masks are copied into owning device storage. The kernel writes the actual candidate pointer with the supplied strides on the borrowed runtime stream. An owning completion guard joins the queue before copied mask storage is destroyed. Native adapter inspection/mirror and its transaction remain authoritative.

Modes are test-only: 0 finite answer7, 1 throw after completed candidate writes, 2 truncated table before callback, 3 NaN written into active candidate cells. Counters are observations after completion, not substitute execution. The constant-answer component is an engineering dispatch witness, not a PDE residual or scientific solver qualification. The physical passive State is preserved; no model-specific runtime behavior is added.

Prerequisite snapshot commit e6a3a946d727671e55debec51cba975be201793c is applied privately as bc620201, production-equivalent to ROOT integration when reviewed. It is separate from this test-only patch and is not included in its commit.

Current verification: genuine complete generated provider and fault-provider Host C++ syntax with POPS_NATIVE_DIM=2 and POPS_HAS_KOKKOS=1, readonly Kokkos ir17 headers. Source package tests only. CUDA/HIP execution, public Native transaction rollback, MPI device buffers and CP/restart are not qualified by these checks. Runtime nodes will be dispatched by ROOT against a rebuilt authenticated SDK. No setup/install or remote source changes were made.

This patch depends separately on snapshot e6a3/a548/4768/93b6 and CPU test support ac6e/48e28. ROOT integrates those prerequisites separately. Public snapshot execution requires the fresh SDK30 reconstruction; SDK29 identities are not inherited. The four runtime parameters are positive, callback_throw, table_preparation and nonfinite in test_gpu_external_field_dispatch_runtime.py. C25 require is declared before resolve; resolution errors are voted before compilation.

The completed Host probe invokes the real generated table callback with allocated Kokkos storage, non-contiguous strides, inactive padding, finite writes, NaN writes and a throw after the fence. It passed with clang++, Kokkos ir17 and one OpenMP thread. This is not CUDA execution. Runtime captures cover full State storage, valid Field values, clock and observed cursors; they do not add a checkpoint/restart, full Field ghost, history or PDE-residual claim.
