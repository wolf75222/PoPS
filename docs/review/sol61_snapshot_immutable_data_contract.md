# Immutable-data snapshot contract @1

An explicit exact integer `__pops_snapshot_immutable_data__ = 1` opts a frozen dataclass into an authenticated data boundary. `snapshot_data()` adds a strict-data receipt; it never replaces the stored authority. Every actual dataclass field (including private and compare-disabled fields), qualified record type, user method implementation and non-field static class namespace are retained. Mutable or opaque static class authority is refused; changing immutable class pins changes the fingerprint. Undeclared stored slots or dictionary fields, mutable/opaque/callback stored leaves, cycles, malformed markers and mutation during projection are refused. Mapping-proxy contents are copied and rechecked; a changed backing map changes the fingerprint.

User methods retain the existing callable projection: bytecode, defaults, annotations, closures, referenced globals and builtins. Framework dependencies use the existing authenticated framework source dependency boundary. Ordinary executable callbacks retain their previous snapshot path. A callable frozen record is admitted as a data factory only with the same explicit protocol and a strict receipt; its actual method implementation and entire stored authority remain authenticated. It does not make callable stored leaves admissible.

External component factories and instances verify their actual source package, exported component manifest and interface before producing the receipt. The stored package source bytes, manifest/interface versions, identity, paths and DSO pins (when present) remain in the structural tree. No component/model/class-name exemption is used in the snapshot encoder. This fixes the genuine public ExternalFieldSolver composition whose previous structural traversal cycled through the implementation registry.

The exact parent `72eb41ae1aff3d085353fcd23661757d9119badb` reproduces the Source refusal; its XML/log are preserved in `sol61-external-field-dispatch-fault-preparation-20261004`. Source checks and tiny component host compilation are preparation only. No installed simulation, MPI execution, rollback, or scientific qualification is claimed. Native dispatch fixtures are a separate change and independent review is required before integration.

The callable-first-projection and static-class-pin omissions found during independent review remain preserved as REDs. Factories now establish their stored baseline before any receipt callback, and static class authority is included rather than treating frozen instances as frozen classes.

Every Python method is authenticated, including dataclass methods and custom dunders compiled by exec. A filename is not proof of generated authority. The method-dependency encoding explicitly authenticates the identity of the dataclasses MISSING/default-factory sentinels and builtins NotImplemented/Ellipsis against their implementation module; these are not admissible opaque stored data leaves.
