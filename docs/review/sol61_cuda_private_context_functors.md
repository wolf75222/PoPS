# Named device callables for two private runtime paths

Parent Source is cabd2f0199a6fbe65ba6c203f74ba37679192a88 (production6f).
The genuine CUDA SDK36 build733176 refuses extended device lambdas emitted inside
private runtime members. This bounded delta changes only two such sites.

* Hierarchy original-candidate finitude uses a named detail callable carrying the
  same view and component width, scans all components of the same grown box,
  returns1 for the same nonfinite predicate, and retains the fence/refusal.
* Coupled frequency uses a named TU-local callable carrying the same
  CoupledFreqKernel value. It initializes lowest(), invokes the same postfix
  evaluator and returns the same result over the same valid reference box.
  Input/component/register order, constants, reduction and collective maximum
  are unchanged; this does not add a new NaN policy to the frequency evaluator.

No existing public/private access is changed. No existing storage or DTO layout,
ABI version, checkpoint version, allocation, state/history or effect protocol is
changed. Header signature changes require matching rebuilt JIT/Native artifacts.
No flags, equations, thresholds, model names or dimensions are specialized.

Source/Host checks compile and execute real FieldView and Kokkos reductions for
dimensions1/2/3, component2, unequal per-cell values and ghost-only NaN, and retain
the previous NaN-frequency behavior. The whole system_install.cpp translation
unit is syntax-checked with current headers and readonly ir17 dependencies.
These checks are not NVCC compilation, Native runtime or MPI/GPU qualification.
ROOT owns the strict-flags original/candidate CUDA comparison and later rebuild.
