# Compact SDK20 receipt copies

These six JSON files and the build script are byte-exact copies of received ROOT
artifacts. `receipt-index.json` records their immutable external origins and hashes.
The full raw archives and independent readers remain at those origins. Counts for
helper pins and complete Native envelopes have different explicitly named domains.
The failed Fan-Li Native node remains FAILED; its nine saved images pass a separate
offline mathematical reader. No current Native end-to-end scientific PASS follows.
