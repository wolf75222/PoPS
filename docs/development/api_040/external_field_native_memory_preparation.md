# External FieldSolver native-memory adapter contract

The public adapter is `pops.fields.external-field-solver.system-amr-native-memory@4`, with use policy version 6 and resolver/installer identities `@4`. FieldSolverV2/FieldTopologyV2 already carry ExecutionContextV1 and residence-tagged field views; the C ABI tables, requests and shared-state layouts are unchanged. The exact pair remains indivisible from resolution through native installation. This source extension is not a GPU execution certificate.

The interface target filter admits native float64 CPU/CUDA/HIP/SYCL/OpenMPTarget variants only for FieldSolver@2 and FieldTopology@2, alongside the existing Tagger route. All other protocols retain their previous envelope. Provider capabilities intersect the actual ranked device variants of both roles and retain only common features. A CUDA topology and HIP solver do not form a pair, nor do disjoint dimensions. GPU and MPI capability values describe component declarations and adapter admission; the existing component compiler still selects the exact RuntimeInstance device/dimension and authenticates its package. No CPU substitution or backend kernel implementation is introduced.

The adapter tags every RHS/solution view with actual MultiFab memory. On the new nonHost route it additionally checks accessible memory, the exact compiled ExecutionSpace name, the corresponding device identity, and binary64 compute/accumulation/reduction. Native streams can be borrowed only by an actual CUDA or HIP execution type. An enabled CUDA/HIP macro does not allow SYCL/OpenMPTarget to ignore a foreign nonzero stream. Host numerical controls, candidate contents and native identity byte assembly follow the existing route; public authority changes require fresh resolution and rebuilt headers/components.

A callback completion guard wraps the exact borrowed CUDA/HIP stream in its execution instance, fences that instance and Kokkos work after the callback, and joins again during exception unwinding before the existing collective failure vote. The runtime retains stream ownership. No stream is created by the production adapter. A throwing callback propagates through the existing collective failure/outer transaction mechanism before accepted publication.

Active valid scalar cells are checked against immutable prepared material masks. Host fields retain direct inspection. Device and managed fields use a new owning HostSpace allocation containing the exact positive-stride valid span, filled by synchronous deep copy after callback completion. The copy only inspects; it does not solve, refresh, overwrite or publish. Mirror allocation/copy/descriptor failures enter the collective preflight vote, including ranks with zero local patches. Nonfinite active cells retain the invalid-evaluation/fail-run report; inactive cells and ghosts are outside the solved-value certificate. Embedded/cut-cell topology remains refused by the public policy, and its independent host-readable validation is unchanged.
