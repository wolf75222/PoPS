Payload v12 requires state_carriers_checkpoint, a one-dimensional uint8 transport of the native POPSCAR1 image (pops.amr.state-carriers-checkpoint@1). The C++ effect captures every block, active level, global patch, component and complete grown storage, with exact Real bits and source owner authority. The native source validator is non-mutating and checks schema, dimensions, scalar width, block identities, complete source patch coverage and consensus before the restart transaction. It does not confuse source geometry with a freshly bound destination. The final restore checks the rebuilt target geometry and every valid bit against the saved scientific projection, stages full storage, retains target allocations and votes device copy/fence failures. The enclosing native restart transaction owns rollback. The effect runs after history replay, clocks and field warm starts, before exact accepted-contract validation or RegridOnRestart. It performs no solver or field recompute.
