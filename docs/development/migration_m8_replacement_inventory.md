## Evidence rules

The words **source**, **executed**, and **qualified** have separate meanings here.

- **Source** means that the symbol, contract, refusal, or test is present in the inspected tree.
- **Executed** means that a named test or command ran at a stated source pin and has a retained
  receipt. A failed attempt is still an executed attempt, never a passing gate.
- **Qualified** requires the current M3-M8 replacement matrix at the same source and native artifact, with
  the declared numerical, restart/output, collective, and configuration oracles. Unit tests,
  syntax checks, static scans, source/package authentication, and a source implementation do not
  establish bind, scientific, or performance qualification.

The required configuration axes are at least `{Dim, backend, MPI ranks, levels, blocks, restart,
output}`. A row below that names a dimension or backend is a source envelope or a bounded test
scope, not a universal product promise. Unsupported configurations must remain explicit
refusals until a replacement and its oracle exist.
